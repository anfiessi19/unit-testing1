# Common Work Reverse

This repository is created as part of a collaborative university assignment.

## Description

The owner will create an issue describing a programming task.
The contributor will implement the solution in a separate branch
and submit a pull request for review.

## Workflow

1. Owner creates an issue with a task description
2. Contributor clones the repo and creates a new branch
3. Contributor implements the solution and opens a pull request
4. Owner reviews, requests changes if needed
5. Contributor fixes issues and re-requests review
6. Owner approves and contributor merges
